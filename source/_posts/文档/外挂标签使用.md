外挂标签可以在 Markdown 中快速插入图表、画廊、视频、按钮等丰富内容。内置标签无需额外安装；插件标签需要先安装对应插件，再按照示例调用。

> 建议优先使用内置标签。只有在确实需要扩展能力时，再引入额外插件，以减少依赖和维护成本。

## Butterfly 兼容说明

从 `hexo-solitude-tag@1.1.0` 开始，Solitude 已兼容 Butterfly 文档中的 14 组原生外挂标签。GalleryGroup、Gallery、Mermaid、Tabs 继续由主题提供，其余语法由插件提供，并统一使用 Solitude 的视觉样式。

| Butterfly 标签组 | 可用语法 | 提供方 |
| --- | --- | --- |
| GalleryGroup | `galleryGroup` | Solitude 主题 |
| Gallery | `gallery` | Solitude 主题 |
| Tag-hide | `hideInline`、`hideBlock`、`hideToggle` | `hexo-solitude-tag` |
| Mermaid | `mermaid` | Solitude 主题 |
| Tabs | `tabs` | Solitude 主题 |
| Button | `btn`，并保留 `button` | `hexo-solitude-tag` |
| InlineImg | `inlineImg`，并保留 `inline_img` | `hexo-solitude-tag` |
| Label | `label` | `hexo-solitude-tag` |
| Timeline | 注释块写法，并保留 `timeline` + `timenode` | `hexo-solitude-tag` |
| Note | `note`、`subnote` | `hexo-solitude-tag` |
| Flink | `flink` | `hexo-solitude-tag` |
| ABCJS | `score` | `hexo-solitude-tag` |
| Series | `series` | `hexo-solitude-tag` |
| Chart.js | `chartjs` | `hexo-solitude-tag` |

从 Butterfly 迁移时，大多数文章无需修改。旧版 Solitude 的 `button`、`inline_img`、`timeline` + `timenode` 语法仍然有效；Butterfly 的 `btn`、`inlineImg`、`subnote` 和注释块 Timeline 可以直接使用。

`hexo-solitude-tag@2` 面向 Hexo 8，需要 Node.js 20.19 或更高版本。它保留 1.x 的标签语法、配置项和输出类名，但把浏览器逻辑改为全站共用的可缓存资源，并在 PJAX 跳转时清理图表、复用仓库请求。仍在使用 Hexo 7 或旧版 Node.js 的站点应继续使用 `hexo-solitude-tag@1`。

> 2.0 正式发布前，本 Demo 的 Registry 依赖仍保持在可安装的 1.1.x；本文中的标签效果与 2.0 保持兼容。

## 插件标签

安装插件

```bash
npm i hexo-solitude-tag
```

2.0 环境要求：Hexo 8、Node.js 20.19+。从 1.x 升级不需要改写文章或 `solitude_tag` 配置。

<!-- endchart -->
<!-- desc -->
Butterfly 14 组标签的提供方分布。
<!-- enddesc -->
{% endchartjs %}
